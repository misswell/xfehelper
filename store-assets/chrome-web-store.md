详细说明：

> XFeHelper 是面向前端开发者的本地工具箱，提供 JSON 格式化与对比、编码解码、二维码、代码美化、正则、时间戳、UUID、图表、Excel 转换、网页调试和自定义工具等功能。所有内置工具随扩展提供，默认启用，离线即可使用。

单一用途说明：

> XFeHelper 是一款面向前端开发者的离线工具箱，用于在浏览器中完成 JSON、编码解码、二维码、代码处理、页面调试和开发效率工具操作。所有内置工具服务于前端开发与网页调试这一单一用途，不用于广告、跟踪或收集用户浏览数据。

## 权限说明

远程代码理由：

> 扩展不从第三方网页远程加载内置功能代码。为支持用户主动导入或创建的自定义开发工具、油猴脚本和开发者工具补丁，扩展会在用户明确触发后读取用户提供的脚本，并在隔离沙盒或目标页面上下文中执行。这些脚本由用户选择或配置，不用于广告、跟踪或隐藏下载。

主机权限理由：

> 网页工具、网页油猴以及 JSON 格式化、截图等功能需要在用户当前打开的 http、https 或 file 页面读取选中内容、访问 DOM、注入工具脚本和样式；权限仅用于用户主动使用相应功能。

`activeTab` 权限理由：

> 用户点击扩展按钮、工具或右键菜单后，临时访问当前标签页，用于读取选中内容、注入用户选择的工具、执行页面格式化或截图等操作。

`alarms` 权限理由：

> 用于每天触发一次后台更新检查，检查内置工具和扩展版本相关信息，并在需要时通知用户；不用于广告或用户行为跟踪。

`contextMenus` 权限理由：

> 提供右键菜单入口，让用户对当前页面或选中文本直接调用 JSON 格式化、编解码、页面工具等功能。

`downloads` 权限理由：

> 用于用户点击导出或下载时保存 JSON、图片、截图、代码或其他工具结果；仅在用户发起下载时调用。

`notifications` 权限理由：

> 用于显示用户发起的下载、更新检查、导入、工具安装和操作结果提示，不推送广告。

`scripting` 权限理由：

> 用于在用户主动调用工具、右键菜单或网页油猴功能时，将扩展内置的工具脚本和样式注入当前页面或执行页面操作。

`storage` 权限理由：

> 用于保存用户的工具设置、主题、收藏、已安装自定义工具、便签和工作状态，使其在扩展页面和浏览器重启后保持。

`tabs` 权限理由：

> 用于识别用户当前活动标签页、打开工具页面、读取页面地址或标题，并将用户发起的工具操作应用到正确标签页；不用于后台监控浏览历史。

`unlimitedStorage` 权限理由：

> 自定义工具、便签、日志和用户保存的配置可能超过普通扩展存储额度，因此需要更大的本地存储空间；数据只保存在用户浏览器本地。

`webNavigation` 权限理由：

> 网页油猴功能需要在页面提交、加载和历史状态变化等导航节点触发用户已配置的脚本；仅处理用户启用的脚本，不记录或上传浏览历史。

## 隐私权规范页

按当前实现填写：

- 用户数据：不出售、不转移给第三方、不用于广告、不用于信用评估或贷款资格判断。
- 数据收集：扩展不收集或上传用户输入、网页内容、浏览历史、身份信息、财务信息或健康信息；工具输入和设置只在本地浏览器处理或保存。
- 隐私权政策网址：`https://fehelper.com/privacy-policy.html`
- 勾选“确认数据使用情况符合开发者计划政策”。

## 发布前检查

1. 上传 `output-chrome/xfehelper.zip`，不要上传源码目录。
2. 确认商品图标使用 128×128 的 `apps/static/img/fe-128.png`。
3. 上传至少一张 1280×800 截图；当前资料已准备两张。
4. 选择简体中文和“开发者工具”。
5. 填完隐私权规范页后点击“保存草稿”，再重新运行发布检查。
